# BotSpace conversation/message extension — 7 October 2026

The existing service now provides contact creation, conversation lookup/creation, explicit template/session messaging, message inspection, and delivery-status polling. The form attempts contact preparation and conversation lookup after Zoho sync. MongoDB persistence remains its success condition. No messages are sent automatically, and no live services were called.

**Remaining contract limitation:** automatic conversation creation after a failed/empty lookup is not enabled. The inspected Swagger documents a successful lookup but no not-found response. `ensureConversation(row, { absenceConfirmed: true })` supports creation after a trusted caller independently confirms absence. Arbitrary errors/404s never trigger creation. This is intentionally narrower than the requested fully automatic lookup-then-create flow until the provider's absence contract is confirmed.
